# Results

Rules: R20–R22, C3, I2. Purpose: present experimental outcomes **without interpretation**.

## Answer only
- What was obtained from the experiments? What data was collected? What are the measured outcomes?

## How
- Aggregated/summarized data (means, medians, SD, CI, counts, effect sizes, test statistics) — not raw data; raw data goes to an appendix or repository.
- Choose the visualization by data type:

| Data / message | Visualization |
|---|---|
| Exact values, many metrics | Table |
| Comparison between groups/methods | Bar chart, box plot |
| Distribution | Histogram, box/violin plot |
| Change over time / epochs | Line chart |
| Relationship between two variables | Scatter plot |
| Classification performance | Confusion matrix, ROC/PR curves |
| Proportions (few categories) | Stacked bar (avoid pie with many slices) |

- Organize results by hypothesis or research question, in the same order as the Method.
- Report statistical tests completely (test, statistic, df, p, effect size) — values come from the author (I2).
- A concise style is acceptable: "The results are shown in Figure 1."

## Interpretation words to avoid here
"this shows that", "this indicates", "because", "due to", "suggests", "demonstrates", "surprisingly", "as expected", "which means", "isto mostra", "isto indica", "devido a", "sugere", "demonstra", "o que significa", "esto muestra", "lo que indica", "debido a", "cela montre", "ce qui indique", "en raison de". Move those sentences to the Discussion.

## Merging with Discussion (R22)
Only if the venue requires. Even then, keep the outcome sentence before the interpretation sentence.
