# Discussion

Rules: R23–R28, C2–C4, I3. Purpose: interpret and explain the results.

## Required elements
1. **Interpret results** (R23) — explain meaning; do not repeat numbers except to anchor the argument.
2. **Explain relationships** (R23) — connect findings and make the reasoning chain explicit.
3. **Evaluate hypotheses** (R24) — for each hypothesis from the Method:
   > "H1 [supported / not supported]: [test], [statistic], p = [value], effect size = [value]. Therefore H0 [is rejected / cannot be rejected]."
   If the evidence is missing, write `[STATISTICAL EVIDENCE PENDING: H1]` (I3).
4. **Discuss findings** (R25) — supporting evidence, unexpected findings, exceptions, missing correlations, limitations.
5. **Compare with previous studies** (R26) — similarities and differences with the works from Related Work (and others), with citations.
6. **Self-contained** (R27) — the reader should not need other papers; do not leave interpretation to the reader.
7. **Threats to validity** (R28) — revisit each threat planned in the Method and state how it may affect interpretation and what mitigated it.

## Structure suggestion
One subsection per hypothesis/RQ → unexpected findings → comparison with literature → threats to validity.

## Common mistakes
- Repeating the Results section.
- Claiming causality from correlational designs.
- Ignoring negative or null results.
- New results appearing only in the Discussion (C3).
