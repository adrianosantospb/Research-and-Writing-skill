# [EXTENSION] Document type: Undergraduate thesis / monograph (TCC)

## Typical structure (ABNT NBR 14724 + the guideline)
**Pre-textual**: cover, title page, (errata), approval sheet, (dedication, acknowledgments, epigraph), abstract in the main language + keywords, abstract in a foreign language + keywords, (lists of figures/tables/abbreviations/symbols), table of contents.
**Textual**:
1. Introduction — guideline elements (R03–R09) + general objective, specific objectives, (research questions / hypotheses), justification (business + technical problem), expected contributions. Optional "Organization of the work" paragraph — **the writer decides**.
2. Background (theoretical foundation) — `../extensions/theoretical-foundation.md`.
3. Related work — 4-part analysis + comparative table (R11–R13).
4. Method — proposed solution, methodology classification in prose, models, planning (R14–R19).
5. Results (R20–R21).
6. Discussion (R23–R28) — may be merged with Results if the program allows.
7. Conclusion — contributions, objectives check, future work (R29–R32).
**Post-textual**: references, (glossary, appendices, annexes, index).

## Notes
- Scope is smaller: hypotheses may be replaced by research questions; still define how each objective is evaluated.
- Each specific objective should map to a method step and to a result (traceability).
- Confirm the institution's template and the ABNT editions it adopts.
- Write headings in the manuscript language.
