# References section

Rules: R33, C8, I1.

1. Ask (or infer from the venue/institution) the required style and load the matching file in `../citation-styles/`.
2. Every in-text citation has an entry and every entry is cited (C8).
3. Never fabricate entries or complete missing fields by guessing (DOI, pages, volume). Mark `[MISSING FIELD: DOI]`.
4. Prefer DOIs for articles; include access dates for web resources when the style requires.
5. If the author uses LaTeX, give the BibTeX/biblatex setup listed in the style file; if Word/Zotero/Mendeley, name the style to select.
6. Consistency check: same style for all entries, same author-name format, same capitalization policy for titles.
