# [EXTENSION] Ethics, data availability and AI-use disclosure

## Ethics
- Research with human participants (interviews, questionnaires, user studies, health data) usually requires approval **before** data collection:
  Brazil — CEP/CONEP via Plataforma Brasil (report the CAAE number); elsewhere — IRB/ethics committee.
- Report in the Method: approval body and number, informed consent procedure, anonymization, data storage.
- Personal data: mention compliance with applicable law (e.g., LGPD in Brazil, GDPR in the EU) when relevant.
- Never invent approval numbers: `[DATA PENDING: CAAE number]`.

## Data and code availability
- Statement saying where data, code and models are available (repository + DOI, e.g., Zenodo), under which license, or why they cannot be shared.
- Many venues require it; it also mitigates external and conclusion validity threats.

## AI-use disclosure
- Many publishers require declaring the use of generative AI tools in writing or analysis, and do not accept AI tools as authors.
- When this skill helped write the text, recommend that the author check the venue's policy and add a statement such as:
  > "During the preparation of this work the author(s) used [tool] to [purpose, e.g., improve readability / structure sections]. The author(s) reviewed and edited the content and take full responsibility for it."
- Place it where the venue specifies (acknowledgments, methods, or a dedicated statement).
